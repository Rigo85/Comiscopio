# Comiscopio 0.3.0

- Windows 10/11 x64: paquetes portable EXE y ZIP con lectores y dependencias
  incluidos, también para ACE/CBA, BMP y AVIF.
- Lectura de carpetas de imágenes con subcarpetas, orden natural y rutas Unicode.
- Correcciones de scroll de miniaturas, rueda, drag-and-drop y aperturas rápidas.
  Abrir un archivo que ya tiene ventana activa vuelve a esa ventana.
- Vista previa y extracción del CB7 sólido comparten el bloque descomprimido,
  evitando decodificarlo dos veces. Mejoras en la cola de miniaturas y la caché.
- Páginas dañadas muestran un marcador de error y permiten continuar leyendo.
  Los errores de SQLite conservan la base de datos en lugar de borrarla.
- Limpieza de workers, auxiliares y temporales al cambiar de archivo y cerrar
  la aplicación. ACE aplica límites de 10.000 entradas, 512 MiB por entrada y
  8 GiB totales descomprimidos.
- Angular, Electron, SQLite y lectores nativos actualizados. Pruebas de los
  paquetes Linux y Windows incorporadas al pipeline antes de publicar.

## Descargas

- Linux x64: `Comiscopio-0.3.0.AppImage` y `comiscopio-0.3.0.tar.gz`.
- Windows x64: `Comiscopio.0.3.0.exe` y `Comiscopio-0.3.0-win.zip`.
- `SHA256SUMS.txt`: sumas de verificación de los paquetes publicados.

## Observaciones conocidas

- DjVu permanece delegado a MuPDF; no se confirma soporte efectivo en las
  bibliotecas incluidas.
- En las VM Windows de validación se observaron aperturas iniciales lentas que
  no se reprodujeron en todas las repeticiones. La causa no está determinada;
  no se atribuye de forma concluyente a la virtualización ni se declara corregida.
- Algunos PDF generan advertencias CMap de MuPDF sin impedir la navegación.
- Los límites ACE controlan los datos extraídos, no fijan un techo de RAM/CPU.

Los paquetes son portables; no incluyen instalador ni firma de código Windows.
